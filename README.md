# BazarDor 🛒
# Description
BazarDor is a web application where users can check daily prices of essential products in different markets.

## Technologies Used
- Next.js
- React
- Tailwind CSS
- JavaScript
- Better Auth
- DaisyUI
- Vercel

## Features
1. View daily product prices.
2. See price increases and decreases.
3. Browse products by category.
4. View product details and market prices.
5. User login and registration.
6. Sort products by price.
7. Update user profile.
8. Responsive design for all devices.
